# Ikon Gardens Website

Cleaned project version of the Ikon Gardens website.

## Structure
- `index.html` — page markup
- `css/style.css` — all styles and responsive rules
- `js/script.js` — page interactions/theme toggle
- `assets/images/` — extracted image assets (no giant Base64 image blobs in HTML)

## Theme
- Dark: black + gold
- Light: white + gold
- Theme toggle is icon-only and positioned after Contact Us
- Responsive navigation adapts across desktop, tablet and mobile
